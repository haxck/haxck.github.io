当我们听到AI这个词的时候，会觉得这是一门很深奥的学问，再加上一些危言耸听的短视频，会愈发觉得深不可测。其实使用AI很简单，AI就是一个根据你的指令，然会返回你结果的工具，只是给AI下的指令就是我们平常说的语言。
如何让AI听懂我们的话，返回我们想要的结果，这就需要能够清楚地表达需求。清晰无歧义地表达！

我们来看一个例子

```
user: 如何判断苹果好坏？
assistant: 不好意思，我不清楚你所指的“苹果”具体指的是什么，水果还是电子设备。
user: 如何判断苹果手机好坏？
assistant: 检查是否能正常开机，检查电话，音乐，摄像机等应用是否能正常使用...
```

你看，用好AI其实就是学会表达，只要把问题提的具体、无歧义、逻辑清晰且有详细，AI就能给出一个很高质量的回答。除了这些，还可以使用示例的方式，让AI做为参考，那么她将按照你的方式来进行回复。

此外还有一些稍微高级的用法，就是更详细地描述你的需求，称为提示词工程。你可以按照下列方式来组织提问：

### 三种提问框架
- ICIO
	- Intruction（指令）：告诉它需要完成什么任务。    
	- Context（背景）：提供任务的背景信息，帮助AI理解任务的上下文和环境。
	- Input Data（输入数据）：指明AI在执行任务时需要考虑的数据或信息
	- Output Indicator（输出指示器）：定义期望的输出结果，包括格式、内容和质量标准。
- CRISPE
	- Capacity and Role（角色）：明确AI在交互中应扮演的角色，如教育者、翻译者或顾问。	    
	- Insight（背景）：提供角色扮演的背景信息，帮助AI理解其在特定情境下的作用。
	- Statement （任务）：直接说明AI需要执行的任务，确保其理解并执行用户的请求。
	- Personality （格式） ：设定AI回复的风格和格式，使其更符合用户的期望和场景需求。
	- Experiment （实验）：如果需要，可以要求AI提供多个示例，以供用户选择最佳回复。
- RASCEF
	- Role（角色）：定义AI在交互中所扮演的角色，如电子邮件营销人员、项目经理等。	    
	- Action（行动）：明确AI需要执行的具体行动，如编写项目计划或回答客户咨询。
	- Script（步骤）：提供AI完成任务时应遵循的步骤，确保任务的有序进行	    
	- Content（上下文）：提供背景信息或情境，帮助AI理解任务的背景和环境。    
	- Example（示例）：通过具体实例展示期望的语气和风格，帮助A更好地模仿和理解。	    
	- Format（格式）：设定AI输出的格式，如段落、列表或对话，以适应不同的沟通需求。
